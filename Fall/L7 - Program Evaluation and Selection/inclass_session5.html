lifts <- seq(0.0005, 0.005, by = 0.0005)
n_req <- sapply(lifts, function(d)
  power.prop.test(p1 = 0.02, p2 = 0.02 + d, sig.level = 0.05, power = 0.80)$n)
plot(100 * lifts / 0.02, n_req / 1000, type = "b", log = "y",

Small lifts are brutally expensive to detect — this is the Lewis–Rao point about advertising experiments.

Reproduce: randomization inference in ten lines

A small experiment with a skewed outcome — exactly where the t-approximation is shakiest. 40 sellers, half treated, revenue is lognormal, true effect is a 30% lift:

n <- 40
d <- sample(rep(0:1, n / 2))
y <- exp(rnorm(n, mean = 3, sd = 1)) * (1 + 0.3 * d)

observed <- mean(y[d == 1]) - mean(y[d == 0])
perm <- replicate(10000, {
  d_star <- sample(d)               # reshuffle labels, same # treated
  mean(y[d_star == 1]) - mean(y[d_star == 0])
})
c(observed = observed, p_value = mean(abs(perm) >= abs(observed)),
  t_test_p = t.test(y ~ d)$p.value)
##  observed   p_value  t_test_p 
## 4.8027965 0.7583000 0.7291778
hist(perm, breaks = 50, main = "Null distribution, built from the design")
abline(v = observed, col = "red", lwd = 2)

The histogram is the null distribution — no CLT required. Try re-running the chunk a few times: with n = 40 and lognormal outcomes, the permutation and t-test p-values usually agree roughly, but the permutation one needs no approximation to defend.

Reproduce: interference in a marketplace

Buyers share a limited inventory. A coupon raises purchase propensity from 0.20 to 0.30. When supply binds, treated buyers take units control buyers would have bought, and the buyer-level A/B test overstates the effect of giving everyone the coupon.

run_market <- function(treat, supply, p0 = 0.2, delta = 0.1) {
  want <- rbinom(length(treat), 1, p0 + delta * treat); sold <- integer(length(treat)); left <- supply
  for (i in sample(seq_along(treat))) if (want[i] == 1 && left > 0) { sold[i] <- 1L; left <- left - 1 }
  sold
}
B <- 200
for (ratio in c(0.75, 1, 2)) {
  supply <- round(ratio * 0.2 * B)
  est <- replicate(200, { tr <- rbinom(B, 1, 0.5); s <- run_market(tr, supply)
    c(naive = mean(s[tr == 1]) - mean(s[tr == 0]),
      global = mean(run_market(rep(1, B), supply)) - mean(run_market(rep(0, B), supply))) })
  cat(sprintf("supply/demand = %.2f:  buyer-level A/B %.3f   global effect %.3f\n", ratio, mean(est["naive", ]), mean(est["global", ])))
}
## supply/demand = 0.75:  buyer-level A/B 0.056   global effect 0.000
## supply/demand = 1.00:  buyer-level A/B 0.082   global effect 0.008
## supply/demand = 2.00:  buyer-level A/B 0.100   global effect 0.100
